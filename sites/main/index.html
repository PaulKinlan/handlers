Beyond the Tab

How far can an installed web app hook into the operating system, and into other web apps?

Links with custom schemes, files opened from the desktop, the share sheet, launch handling, badges, window chrome, Document PiP, and cross-origin handoffs. Each pattern has a diagram, a live demo where one exists, how it works, what you could build with it, and what goes wrong. The four demo apps run on separate origins, because each registration belongs to an origin.
